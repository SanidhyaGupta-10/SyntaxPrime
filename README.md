# ⚡ SyntaxPrime

> **A refined developer environment designed with clarity, precision, and depth.**

SyntaxPrime is a premium educational platform and developer resource hub focused on deep-level technical notes, professional roadmaps, and high-impact skills. Built with a focus on visual excellence and technical rigor, it provides developers with the structured paths needed to master modern web engineering.

---

## 🌟 Key Features

- **📂 Professional Notes**: Deep-dive documentation on everything from low-level systems to high-level architecture.
- **🗺️ Structured Roadmaps**: Step-by-step learning paths that eliminate guesswork and maintain momentum.
- **🛠️ Real-World Projects**: Hands-on building of production-grade applications that belong in a professional portfolio.
- **⚡ Performance First**: Utilizing smooth scrolling with **Lenis** and optimized 3D rendering with **React Three Fiber**.
- **🎨 Premium UI/UX**: A dark-themed, glassmorphic design system powered by **Tailwind CSS 4.0** and **Motion**.

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm / pnpm / yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/SanidhyaGupta-10/SyntaxPrime.git
   cd SyntaxPrime
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
